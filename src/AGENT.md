## プラグイン開発ディレクトリ

このディレクトリはプラグインごとのディレクトリで構成されています。

## 開発

新規プラウグインを開発したら、このドキュメントのプラグイン一覧を更新します。


## プラグイン一覧
- `chatwork/` Chatwork Room Messenger プラグイン。Chatwork API を利用してルームへメッセージを投稿します。
- `hello_world/` HelloWorld ツールプラグイン。指定した名前に挨拶するチュートリアル実装です。
- `github_workflow_exporter/` GitHub Workflow Exporter プラグイン。ワークフロー公開時に DSL を GitHub へコミットします。
